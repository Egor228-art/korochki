# Корочки.есть

## Быстрый запуск

1. Скачайте репозиторий
2. Распакуйте `pocketbase.zip` в корневую папку проекта
3. Запустите `pocketbase/pocketbase.exe serve`
3. Откройте браузер и перейдите по адресу: `http://127.0.0.1:5500/admin.html`

## Учётные данные

- Администратор: `admin@korochki.est` / `KorokNET`
- Обычный пользователь: зарегистрируйтесь через форму

## Примечание

Все HTML/CSS/JS файлы находятся в папке `pb_public/`
